# Фото товаров

Кладите сюда фотографии в формате **.jpg**. Имя файла: `<модель>-<цвет>.jpg`.

| Модель | Имя модели в файле |
|---|---|
| Стол «Тайфун» | `typhoon` |
| Стол «Био» | `bio-table` |
| Стул с подлокотниками «Био» | `bio-chair` |
| Стул «Илона Лайт» | `ilona-light` |
| Стол «Лофт» | `loft` |
| Стол «Сканди» | `scandi` |
| Стул «Марк» | `mark` |
| Полукресло «Бруно» | `bruno` |

| Цвет покрытия | Цвет в файле |
|---|---|
| Дуб натуральный | `natural` |
| Терра | `terra` |
| Коньяк | `cognac` |
| Графит | `graphite` |

Примеры: `typhoon-natural.jpg`, `typhoon-cognac.jpg`, `bio-chair-terra.jpg`.

Если фото нужного цвета нет, сайт покажет общее фото модели (`typhoon.jpg`). Если нет и его — нарисованный силуэт.

Советы: светлый однотонный фон, горизонтальный кадр примерно 4:3, ширина 1600 px, вес до 400 КБ.
