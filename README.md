# Inter Wood Гомель — прототип сайта

Одностраничный прототип интернет-магазина мебели из массива дуба (Гомель, ТЦ «Мебельный Квартал»).

- Каталог столов и стульев с фильтрами по форме, конструкции и типу
- Карточка товара: выбор размера и цвета покрытия, пересчёт цены
- Корзина, заказ в 1 клик, форма быстрой заявки

Всё в одном файле `index.html` (HTML + CSS + JS), без сборки. Откройте файл в браузере.

> Телефон, Instagram и часть товаров демонстрационные. Заявки пока никуда не отправляются.
